Hướng dẫn chạy Backend: cd backend -> npm install -> npm start. (Ghi rõ Backend chạy ở cổng nào, VD: http://localhost:5000).
Hướng dẫn chạy Frontend: cd frontend -> npm install -> npm run dev
Ghi chú thêm: "Hệ thống sử dụng file JSON để lưu dữ liệu tại thư mục backend/data, vui lòng không xóa thư mục này"
